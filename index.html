Features

Tout ce que VRChat ne montre pas, gardé pour vous.

Une vue claire sur votre univers VRChat — qui vous croisez, ce qu'ils changent, ce que vous explorez.

Recherche multi-DB

Lancez une recherche dans toutes les bases custom + VRCX-compatibles en parallèle. Résultats progressifs, déduplication automatique, enrichissement via l'API officielle.

Logger temps réel

Lit votre log VRChat en direct : entrées de monde, joins/leaves, switchs d'avatar, changements d'amis. Toggles fins, persistance globale et OSC chatbox optionnel.

PrevName persistant

Capture chaque profil rencontré (ID, pseudo, bio, liens, tags). Détecte les changements avec un diff coloré : vert / rouge / orange. Toggle off par défaut.

Get started

3 étapes. Pas d'installation.

Téléchargez le binaire portable, connectez-vous avec votre compte VRChat (2FA supportée), et tout commence à se logger.

2

FAQ

Questions fréquentes.

Si quelque chose manque, ouvrez une issue sur le repo.

Est-ce que mon compte VRChat est en sécurité ?

L'authentification utilise les endpoints officiels VRChat (login + 2FA Email/OTP). Le cookie d'auth reste sur votre machine, dans le stockage local de l'app. Aucune donnée n'est envoyée à un serveur tiers.

Le logiciel est-il vraiment gratuit ?

Oui, totalement. C'est un binaire portable, sans paywall, sans télémétrie. Le code est ouvert.

Le Logger / PrevName tourne-t-il en arrière-plan ?

Oui — le moteur est global et persiste même quand vous changez de page. Un toggle ON/OFF coupe complètement la collecte. PrevName est OFF par défaut.

Pourquoi certaines pages externes (Discord OAuth) ne se chargent pas en iframe ?

Discord et certains sites bloquent l'affichage en iframe (X-Frame-Options: deny). VRC Tracker détecte ce cas et propose un bouton « Open In-App Browser » qui ouvre la page dans une fenêtre top-level Electron, où le login fonctionne normalement.

Est-ce affilié à VRChat Inc. ?

Non. VRC Tracker est un projet communautaire indépendant. VRChat est une marque déposée de VRChat Inc.
